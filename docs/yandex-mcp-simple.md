# Сбор статистики Яндекса одной командой: инструкция для новичка

## Что получится в итоге

Вы сможете одной командой спрашивать у Яндекса: сколько страниц в поиске,
по каким запросам вас находят, что сломалось на сайте, сколько людей приходит
(Метрика). Без браузера и ручного копирования цифр.

## Как это работает (простыми словами)

Ваш компьютер напрямую к Яндексу из программ не достукивается (такая особенность
сети). Поэтому данные идут по цепочке из трёх звеньев:

1. **Форвардер** — маленькая программа-передатчик на вашем компьютере.
2. **SOCKS-прокси** — передатчик на нашем сервере (VPS), уже настроен.
3. **MCP-сервер** — переводчик: превращает ваши вопросы в запросы к Яндексу.

Настраивается один раз за 15 минут. Дальше — только включать.

## Что нужно заранее

- **Git** — проверить: открыть PowerShell и набрать `git --version`. Должен показать номер версии.
- **Node.js 20 или новее** — проверить: `node --version`. Скачать: https://nodejs.org (кнопка LTS).
- **Python 3** — проверить: `python3 --version`. Скачать: https://www.python.org/downloads/
- Доступ к файлу `scripts/.env` в проекте (там лежит ключ-токен от Яндекса).
- Пароль от прокси — в файле `docs/vps.md` (ищите слово SOCKS).

Всё ниже делается в PowerShell в папке проекта `C:\opencode\ortopednn-auto`.

## Шаг 1. Скачать MCP-сервер (один раз)

```powershell
git clone https://github.com/webkoth/yandex-mcp C:\opencode\yandex-mcp
cd C:\opencode\yandex-mcp
npm install
npm run build
```

Что должно получиться: в конце нет красных ошибок, появился файл `dist\index.js`.
Проверка: `Test-Path dist\index.js` должен ответить `True`.

## Шаг 2. Подключить ключ Яндекса (один раз)

Эта команда сама возьмёт токен из `scripts/.env` и запишет в файл настроек.
Сам токен на экране не показывается — так и должно быть.

```powershell
$t=(Select-String -Path C:\opencode\ortopednn-auto\scripts\.env -Pattern '^YANDEX_OAUTH=(.*)').Matches[0].Groups[1].Value.Trim()
$pj=@{projects=@(@{id='ortopednn';token=$t;default_host='https:ortopednn.ru:443';default_counter=109258289})}
[System.IO.File]::WriteAllText('C:\opencode\yandex-mcp\projects.json',($pj|ConvertTo-Json -Depth 4),(New-Object System.Text.UTF8Encoding $false))
```

Файл `projects.json` никуда не отправляется и в общий доступ не попадает
(он в списке исключений git). Никому его не пересылайте — там ключ.

## Шаг 3. Включить передатчик (каждый раз после перезагрузки компьютера)

Откройте отдельное окно PowerShell и запустите:

```powershell
python3 C:\Users\user\AppData\Local\Temp\opencode\fwd-proxy.py
```

Окно должно написать: `forward proxy on 127.0.0.1:8899`. Это окно не закрывать,
можно свернуть. Если закрыли — просто запустите снова.

Проверка, что передатчик жив (в другом окне):

```powershell
curl.exe -s -o NUL -w "%{http_code}`n" -x http://127.0.0.1:8899 https://api.webmaster.yandex.net/v4/user/156937890/hosts/ -H "Authorization: OAuth x"
```

Должно ответить: `403`. Не пугайтесь: 403 здесь означает «связь есть,
а тестовый ключ ненастоящий». Если висит и пишет ошибку — передатчик не запущен,
вернитесь к началу шага 3.

## Шаг 4. Запросить статистику

```powershell
cd C:\opencode\yandex-mcp
$env:HTTP_PROXY='http://127.0.0.1:8899'
$env:HTTPS_PROXY='http://127.0.0.1:8899'
$env:NODE_OPTIONS='--use-env-proxy'
```

Три строчки выше — обязательны каждый раз в новом окне (они действуют только
внутри этого окна). Без третьей строчки программа будет молча игнорировать
передатчик — это самая частая ошибка.

Дальше примеры вопросов (каждый — одна команда, ответ — цифры):

- Сводка сайта: сколько страниц в поиске, исключено, оценка качества.
- Топ запросов: по каким фразам вас находят, сколько показов и кликов.
- Диагностика: что Яндекс считает проблемами сайта.
- Переобход: попросить Яндекс заново зайти на конкретную страницу.
- Метрика: визиты, просмотры, источники трафика.

Точные названия команд и примеры — в таблице файла `docs/yandex-mcp.md`
(техническая версия этой инструкции).

## Если что-то сломалось

| Что видите | Что делать |
|---|---|
| `fetch failed` | Не запущен передатчик (шаг 3) или забыта строчка `$env:NODE_OPTIONS='--use-env-proxy'` |
| `403`, `invalid token` | Протух ключ Яндекса. Обновить токен в `scripts/.env`, повторить шаг 2 |
| Команда висит дольше минуты | Проверить передатчик командой из шага 3; проверить интернет |
| `Проект/файл не найден` | Убедиться, что команды запускаются из нужной папки (`cd`), пути буква в букву |
| Перезагрузили компьютер | Повторить шаг 3 (передатчик), остальное настроено и сохранилось |

## Словарик

- **Вебмастер** — панель Яндекса для владельцев сайтов: поиск, страницы, ошибки.
- **Метрика** — счётчик посещений (кто пришёл, откуда, что смотрел). Наш счётчик: 109258289.
- **SOCKS-прокси** — сервер-посредник на нашем VPS, через него идёт связь.
- **Форвардер** — программа на вашем компьютере, соединяющая MCP-сервер с прокси.
- **Токен/OAuth** — секретный ключ вместо пароля. Никому не показывать, в чат не вставлять.
- **MCP** — способ задавать программам вопросы на обычном языке вместо кнопок.

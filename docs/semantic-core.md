# Семантическое ядро: инструкция

Что это: карта всех запросов сайта. Показывает, какая тема уже закрыта статьёй,
какая свободна, а какая запрещена. Лежит в `data/semantic-clusters/`.

## Файлы

| Файл | Что внутри |
|------|-----------|
| `data/wordstat/vse.csv` | Вход: запросы сайта (`фраза;частота`, 5009 строк) |
| `data/wordstat/<тема>.csv` | Вход: спрос по отдельной теме с частотами Wordstat |
| `data/semantic-clusters/vse.md` | Выход: вся карта, читать этот файл |
| `data/semantic-clusters/<тема>.md` | Выход: разбор отдельной темы |
| `scripts/semantic-cluster.mjs` | Скрипт сборки, зависимостей нет |

## Как обновить (3 шага)

1. Положить CSV `фраза;частота` в `data/wordstat/<имя>.csv`.
2. Запустить `node scripts/semantic-cluster.mjs data/wordstat/<имя>.csv`.
3. Открыть `data/semantic-clusters/<имя>.md`, проверить вердикты.

## Как читать вердикты

| Вердикт | Значение | Действие |
|---------|----------|----------|
| covered: slug | Тема закрыта статьёй | Новую не писать, сослаться на slug |
| GAP | Свободная тема | Кандидат на статью |
| JUNK | Мусор (ОМС, цены, гео, вакансии) | Не писать никогда |

Рядом со slug стоит score: чем выше, тем точнее попадание. Ниже 0.3 маппинг не показывает.

## Перед написанием статьи (обязательно)

1. Открыть `data/semantic-clusters/vse.md`, найти тему через Ctrl+F.
2. covered — писать запрещено без смены угла. GAP — можно.
3. После публикации добавить запрос в `data/wordstat/vse.csv` и пересобрать.

## Ограничения (знать, не чинить на ходу)

- У `vse.csv` все частоты равны 1: это карта покрытия, а не спроса.
  Настоящий спрос — только в тематических CSV с частотами Wordstat.
- Маппинг сравнивает с заголовками статей, вопросы из H2 он не видит:
  часть GAP на деле уже закрыта. Сомневаешься — проверь поиском по сайту.
- Кластеры с гео «нн» и «нижний новгород» — свои, не мусор.

## Где что храним

| Тип информации | Место | Пример |
|----------------|-------|--------|
| Правила | Только `AGENTS.md` | Хард-правила 1–16 |
| Знания, решения (почему) | `wiki/` + запись в `index.md` и `log.md` | Почему не пишем ОМС |
| Инструкции (как делать) | `docs/` | Этот файл |
| Машинные данные | `data/` | Статьи, кластеры, цены |
| Учёт статей | Только `CONTENT.md` | Список опубликованного |

Новое кладётся в своё место сразу. Дубли запрещены: одно место — один тип.
Если место неясно — спросить, а не создавать новый файл.
